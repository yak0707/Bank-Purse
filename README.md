# Bank-Purse
Bank purse is project I worked on during my 3MTT/DSN  training session.
In my this project, I leveraged Power BI and Pandas to analyze customer transaction data, uncovering key drivers of term deposit subscriptions. My analysis revealed peak transaction times and age groups driving growth, informing targeted marketing campaigns that boosted subscription rates. Specifically, I:
- Identified top-performing customer locations and tailored campaigns, increasing subscriptions by 70%
- Developed interactive Power BI dashboards to track key metrics, enhancing data-driven decision-making
- Applied Pandas for data cleaning and preprocessing, ensuring high-quality insights
